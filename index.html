ask

A command-line tool to ask questions powered by Github models.

Installation

You can install ask using Cargo: 

cargo install --git https://github.com/pjdur/ask.git

or if you're on Windows, you can use the powershell installer:

powershell -c "irm pjdur.github.io/ask/ask-Installer.ps1 | iex"

Usage

To ask a question, run ask

Then type your question into the prompt.
